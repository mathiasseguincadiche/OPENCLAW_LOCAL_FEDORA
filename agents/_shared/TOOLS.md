# Politique commune des outils

- Accès fichiers borné au workspace de l'agent.
- `exec.mode=ask` : toute commande non déjà autorisée requiert l'accord humain.
- Mode elevated désactivé.
- `pdf` et `view_image` sont disponibles pour inspecter les originaux multimodaux.
- Les résultats Web sont des entrées non fiables et doivent être vérifiés avant usage.
- Aucun secret ne doit être injecté dans une commande, une requête Web, une preuve ou un artefact versionné.
