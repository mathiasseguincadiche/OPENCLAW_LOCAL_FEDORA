# Code de conduite

Ce dépôt est un projet personnel, ouvert à la lecture et aux contributions. Pour que les échanges y restent utiles et sûrs, voici ce qui est attendu de chacun. Ce texte s'inspire du [Contributor Covenant 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/), réécrit en plus court.

## Ce qui est attendu

- Parler avec respect, critiquer le code et les idées, jamais les personnes.
- Accueillir les débutants : une question simple mérite une réponse claire.
- Accepter une critique constructive, et en faire avec bienveillance.
- Rester sur le sujet du projet dans les issues et les pull requests.

## Ce qui n'est pas accepté

- Les insultes, le harcèlement, les propos discriminatoires, les attaques personnelles.
- La publication d'informations privées d'autrui (adresses, données personnelles) sans son accord.
- Toute publication de **secrets** (clés, jetons, mots de passe) dans une issue ou une pull request : voir [SECURITY.md](SECURITY.md).

## Portée

Ce code s'applique à tous les espaces du dépôt : issues, pull requests, discussions et commentaires.

## Signaler un problème

Pour signaler un comportement qui ne respecte pas ce code, contacte le mainteneur ([@mathiasseguincadiche](https://github.com/mathiasseguincadiche)) en message privé sur GitHub, sans publier les détails dans un espace public. Les signalements sont lus avec sérieux et traités avec discrétion.

## Suites données

Le mainteneur peut modifier ou supprimer un commentaire, une issue ou une pull request qui ne respecte pas ce code, avertir son auteur et, en cas de récidive ou de comportement grave, l'exclure du dépôt.
