Ces exemples utilisent **Atelier Atlas**, un projet fictif, sans adresse privée, secret, test ou déploiement réel. Ils n'altèrent aucun projet utilisateur.

La proposition Notion utilise une syntaxe de gabarit, à convertir en blocs API après validation. Ne pas publier automatiquement.
