# Cadrer un projet et choisir le mode de travail

1. Déclencher lors d’une création ou reprise de projet, d’un cadrage de mission ou d’une clarification de besoin.
2. Identifier le service, les utilisateurs, les critères de succès et les trois finalités distinctes : réalisation, apprentissage et portfolio.
3. Lire les sources accessibles, identifier l’existant, les contraintes, les décisions validées, les risques et le hors périmètre. Ne pas inventer les données manquantes.
4. Choisir le mode MENTOR (indices sans résoudre l’exercice), AUDIT (lecture seule), RÉALISATION (périmètre délégué) ou DIRECT (réponse immédiate).
5. Présenter un cadrage compact, les dépendances, une première livraison testable, les preuves attendues et les décisions en suspens.
6. Proposer la FICHE_PROJET sans remplacer un document existant. STATUS conserve l’avancement technique; le niveau d’apprentissage reste indépendant.
7. Une approbation du cadrage n’autorise ni publication, ni exécution, ni modification sensible.

## Livraison

Indiquer les éléments lus, les décisions, les fichiers ou pages réellement modifiés, les contrôles effectivement exécutés et les limites. Le Skill ne crée aucun droit d'outil.
